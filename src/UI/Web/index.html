Sozlamalar

KonvertatsiyaBarcha dasturlarda yozuvni yangi alifboga o‘girish.
Chat qisqartmalari“yaxwi” → yaxşi, “korishamz” → körişamiz kabi tez yozilgan shakllarni tuzatish.
Neyron modelLug‘atda yo‘q o‘zbekcha so‘zlarni (yangi so‘zlar, ismlar, kam uchraydigan shakllar) tanib, ularni ham o‘giradi. Boshqa tillardagi so‘zlarga tegmaydi. Kompyuterda ishlaydi, internet kerak emas.
Windows bilan ishga tushirishKompyuter yoqilganda dastur patnisda o‘zi paydo bo‘ladi.
Ish stolidagi belgiIsh stolida YangiAlifbo yorlig‘i: bir bosishda boshqaruv paneli ochiladi.
